## About

Apex Vision Advisors is an SDVOSB (Service-Disabled Veteran-Owned Small Business) based in Houston, Texas. Founded on military discipline, strategic precision, and a commitment to mission success, the firm brings clarity and execution to complex business challenges across both the federal and commercial sectors.

- **8+ Years** of Military Service
- **SDVOSB** Certified Veteran-Owned

## Site Features

- Fully responsive design optimized for mobile, tablet, and desktop
- Dark and light theme toggle with smooth transitions
- Scroll-reveal animations for an engaging user experience
- Military-inspired design palette — dark slate, OD green, and gold accents
- Multi-page layout: Home, About, Services, and Contact

## Getting Started

Clone the repository and open `index.html` in your browser — no build step required.

```bash
git clone <repo-url>
cd apex-vision-advisors
open index.html
```

Or run a local dev server with the Netlify CLI:

```bash
netlify dev
```
